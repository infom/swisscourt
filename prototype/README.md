# SwissCourt — предварительный интерфейс

Самостоятельный кликабельный эскиз для обсуждения рабочих сценариев. Он не выбирает стек основного приложения и не предназначен для реального турнира.

## Запуск

Из корня репозитория:

```powershell
node prototype/server.mjs
```

Открыть http://127.0.0.1:4173. Установка зависимостей не требуется. Сервер слушает только локальный компьютер.

Можно открыть `index.html` двойным щелчком; для синхронизации табло и предсказуемого локального сохранения предпочтителен HTTP-адрес выше.

## Что попробовать

1. На экране игрового дня назначить встречу на свободный корт.
2. Внести счёт: например, 21:17 и 21:19. Корт освободится, результат появится в таблице.
3. Вернуть текущую встречу в очередь без результата.
4. Отметить «Приготовиться» булавкой и открыть табло в отдельной вкладке.
5. Исправить завершённую встречу и посмотреть историю изменений.
6. Скачать выбранный разряд в CSV с разделителем `;` и UTF-8 BOM.
7. В настройках переключиться на «Подготовка дня», изменить состав и параметры, посмотреть и опубликовать первый тур.
8. Проверить узкий экран: интерфейс адаптируется к телефону, нижняя панель заменяет боковую.
9. Перезагрузить страницу: изменения текущего сценария должны восстановиться в том же браузере.

«Турнир идёт» и «Подготовка дня» сохраняются независимо в localStorage. Сброс в настройках затрагивает только выбранный сценарий. Очистка данных браузера удаляет изменения.

## Границы эскиза

- Все имена, рейтинги и результаты демонстрационные.
- Швейцарский турнир представлен подготовленным набором встреч. Генерация следующих туров, bye, снятия и технические результаты не реализованы.
- В сценарии подготовки доступен первый тур на чётном составе. До 6 участников используется круговая расстановка, от 7 — верхняя половина посева против нижней.
- Места ранжируются по турнирным очкам, равные очки дают разделённые места. Бухгольц и Бергер отображаются справочно; окончательные критерии равенства не реализованы. CSV тоже содержит эти предварительные места.
- Импорт BadminTune показан только как шаг интерфейса и явно отмечен как неподключённый.
- Сервер импорта, PWA/service worker, полноценная офлайн-установка, резервные копии и производственная модель хранения не реализованы.
- Сервер предпросмотра не хранит пользовательские данные; данные эскиза остаются в браузере.
- Вкладки одного браузера обновляются через событие storage. Это не синхронизация разных устройств.
- Одновременное редактирование в нескольких вкладках не является поддерживаемым режимом. Открытое окно редактирования закрывается при внешнем обновлении.

## Проверка логики

```powershell
node --test prototype/core.test.cjs
```

Проверяются допустимые партии, окончание встречи, конфликты назначения, возврат в очередь, исправление результата, порог отдыха и круговые пары.

## Файлы

- `index.html` — оболочка.
- `styles.css` — адаптивный интерфейс, диалоги, табло.
- `core.js` — демо-данные и проверяемая логика.
- `app.js` — экраны, взаимодействия и локальное сохранение.
- `server.mjs` — локальный статический предпросмотр без зависимостей.
